# Фото категорий

Добавляйте сюда свои фотографии. Имя файла должно совпадать с `id` категории:

- `panels.jpg` — Щиты и корпуса
- `breakers.jpg` — Автоматы
- `rcd.jpg` — УЗО и Дифавтоматы
- `cable.jpg` — Кабель и провод
- `relay.jpg` — Реле
- `din.jpg` — DIN-рейки
- `sockets.jpg` — Розетки
- `switches.jpg` — Выключатели
- `lights.jpg` — Светильники

Фото будет показываться **по центру карточки вместо иконки**.

Если фото нет, приложение временно покажет иконку категории.

Рекомендуется использовать квадратные JPG-файлы размером от 320×320 px.
