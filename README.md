# ЭлектроМаркет — Flutter-проект

Маркетплейс электротехники с двумя ролями: **Покупатель** и **Продавец**.
Роль определяется способом входа, а не переключателем в приложении.

## Вход

- **Покупатель** — по номеру телефона (`/login/buyer`)
- **Продавец** — по секретному коду (`/login/seller`)
  Демо-код для локального теста: `SELLER-2026`
  В проде проверка кода должна уходить на backend, а не жить в клиенте
  (см. `lib/state/user_provider.dart`)

После входа человек видит только свой раздел профиля (меню покупателя или
продавца) — переключателя ролей в интерфейсе больше нет. Выйти можно кнопкой
«Выйти» в профиле, это вернёт на экран выбора роли.

## Запуск

```bash
flutter pub get
flutter run
```

Для загрузки фото товара (`image_picker`) удобнее всего запускать на реальном
устройстве, эмуляторе Android/iOS или в браузере (`flutter run -d chrome`).
Разрешения на доступ к галерее уже прописаны:
- iOS — `NSPhotoLibraryUsageDescription` в `ios/Runner/Info.plist`
- Android — `READ_MEDIA_IMAGES` / `READ_EXTERNAL_STORAGE` в
  `android/app/src/main/AndroidManifest.xml`

Фото хранятся в памяти как байты (`Uint8List` + `Image.memory`), а не как путь
к файлу — это специально, чтобы код одинаково работал на Android, iOS, Web и
десктопе (`dart:io File` на вебе не работает в принципе).

## Что уже реально работает (не заглушки)

- Вход по роли: покупатель — телефон, продавец — секретный код.
- Каталог с 9 категориями (щиты, автоматы, УЗО, кабель, реле, DIN-рейки,
  розетки, выключатели, светильники), в каждой есть хотя бы один товар —
  расширяется одной строкой в `lib/data/mock_data.dart`, без изменений в экранах.
- Поиск — ищет по названию товара, типу/серии и названию категории.
- Раздел покупателя: заказы, избранное, адреса, история и возвраты.
- Раздел продавца: мои товары, продажи и аналитика, заказы покупателей, выплаты.
- Добавление товара продавцом — форма с валидацией, загрузкой до 8 фото,
  выбором категории, произвольным набором технических характеристик, ценой,
  остатком и описанием. После публикации товар сразу появляется в
  «Мои товары» и в общем каталоге.
- Карточки товаров без фото показывают цветную иллюстрацию по категории
  (медь — защита, синий — монтаж, графит — отделка) вместо пустого места.
- Корзина с пересчётом суммы, валюта — сом.

## Архитектура

```
lib/
  core/          — тема, роутер (go_router), общие виджеты
  models/        — Product, ProductCategory, CartItem, Order, UserRole
  data/          — стартовые данные (замените на репозиторий поверх REST API)
  state/         — провайдеры состояния (ChangeNotifier): каталог, корзина, пользователь
  features/
    auth/        — экран выбора роли, вход покупателя и продавца
    catalog/, search/, cart/, profile/ — основные разделы
```

## Следующий шаг к продакшену

1. Секретный код продавца и номер телефона покупателя сейчас проверяются
   локально в `UserProvider` — замените на реальные вызовы backend (SMS-код
   подтверждения для покупателя, проверка кода продавца на сервере).
2. Добавить слой `repositories/` с интерфейсами (`ProductRepository`,
   `OrderRepository`...) поверх `dio` + REST API вместо `mock_data.dart`.
3. Добавить JWT-аутентификацию (secure storage для токена, интерцептор
   обновления токена в Dio) — экраны и провайдеры менять не придётся.
